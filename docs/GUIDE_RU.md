# Как пользоваться ssh-config-check

Это небольшой учебный анализатор серверной конфигурации OpenSSH. Он объясняет наблюдения и показывает строки исходного файла. Систему не меняет.

## Первый запуск

```bash
python -m ssh_config_check --demo
python -m ssh_config_check --config examples/review.conf
```

В демо специально включены вход root и аутентификация паролем, чтобы было что разобрать. Это не шаблон настройки сервера.

## Как читать результат

- WARN — настройка требует внимания с учётом твоей задачи.
- INFO — известное значение, но не обещание безопасности.
- UNKNOWN — информации не хватает или синтаксис не поддерживается.

Например, пароль может использоваться вторым фактором, поэтому предупреждение о PasswordAuthentication не доказывает уязвимость. Keyboard-interactive часто участвует в MFA и само по себе не считается проблемой.

## Include и Match

В режиме `--config` анализируются только явные глобальные значения до первого Match. Подключаемые файлы не открываются, контексты Match не вычисляются, значения по умолчанию не подставляются. UNKNOWN об этих ограничениях останется в отчёте.

Для итоговых значений используй OpenSSH: сначала вручную проверь доверенный файл через `sshd -t -f FILE`, затем сохрани вывод `sshd -T -f FILE -C user=USER,host=HOST,addr=IP` и передай его программе:

```bash
python -m ssh_config_check --effective effective.txt
```

Параметры пользователя, адреса и хоста должны соответствовать нужному подключению. Один контекст не описывает все подключения. Утилита не проверяет происхождение сохранённого вывода и не определяет настройки уже работающего демона.

## JSON и тесты

```bash
python -m ssh_config_check --demo --format json
python -m unittest discover -s tests -v
```

Без `--strict` готовый отчёт означает код 0. С `--strict`: UNKNOWN — код 2, иначе WARN — код 1, иначе 0. Даже нулевой код не означает полную проверку сервера.

Для начала прочитай analyzer.py, затем tests/test_analyzer.py: тесты показывают порядок директив, неполные данные и обработку ошибок. Не меняй доступ к удалённому серверу, не проверив альтернативный вход.
